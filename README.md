## 📌 Sobre o projeto

Este projeto apresenta minha trajetória profissional, experiências, certificações e projetos desenvolvidos na área de dados.

O objetivo é demonstrar aplicações práticas envolvendo:

- Business Intelligence
- Data Analytics
- Visualização de dados
- Automação de processos
- Soluções orientadas ao negócio
